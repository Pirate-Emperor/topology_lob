# Figures and report snapshot

These images are generated by the experiment pipeline. Synthetic figures use fixed random seeds and are labelled as engineering checks, not market-data results.

| File | What it shows |
|---|---|
| figures/lob_snapshot.svg | A deterministic L2 snapshot and the point cloud used for topology features |
| figures/betti_curves.svg | H0/H1 Betti counts as the Vietoris-Rips radius changes |
| figures/ffd_stationarity.svg | Training-prefix ADF checks for candidate fractional-differencing orders |
| figures/model_comparison.svg | Focal Loss and log-loss control on the synthetic holdout |
| figures/cpp_benchmark.svg | Standalone CPU fractional-differentiation throughput |
| figures/experimental_validation_dashboard.png | Feature/objective ablation, seed sensitivity, walk-forward and placebo results |
| figures/robustness_dashboard.png | Numerical checks and metric sensitivity |
| figures/data_diagnostics_dashboard.png | Spread, imbalance, volatility and Betti-1 diagnostics |
| figures/fi2010_validation_dashboard.png | Measured FI-2010 benchmark results |
| screenshots/report_preview.png | High-contrast summary of a measured synthetic experiment |

The report image uses a light background, large dark text, and embedded DejaVu fonts. This avoids faint text and browser SVG font issues.

There is intentionally no terminal screenshot and no main.png banner.
