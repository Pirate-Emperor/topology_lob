The main README image uses the same simple chart style as the other SVG figures: a white background, standard axis labels, thin grey grid lines, blue and orange bars, and a dashed target line. The separate detailed A100 dashboard is retained for readers who need more experiment detail.

There is intentionally no terminal screenshot and no main.png banner.
